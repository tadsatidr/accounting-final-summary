# Financial Accounting 1 · final review (1/2026)

English study site for the Financial Accounting 1 final, semester 1/2026, covering the lecture slides for:

- Chapter 5 Cash and receivables
- Chapter 6 Inventory
- Chapter 7 Property, plant, and equipment, and intangibles
- Chapter 8 Liabilities

Plus a formula sheet and a journal-entry reference.

The site is plain HTML, CSS, and JS. Open `index.html`, or serve the repository root. It is set up for GitHub Pages **Deploy from a branch**, branch `main`, folder `/` (root). `.nojekyll` is included so Pages serves the files as they are. Links are relative, so the site works at `https://tadsatidr.github.io/accounting-final-summary/`.
